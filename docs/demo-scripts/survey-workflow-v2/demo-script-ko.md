# 설문 품질관리 3단계 V2

## Target App Brief

- Target apps: 설문 복원 및 코드북, Survey Quality Review, Persona Pilot
- Audience: CI 간부와 조사 프로젝트 책임자
- Video type: product demo
- Main promise: 같은 설문을 `복원 → 결정적 오류 검증 → 인구학적 합성 파일럿` 순서로 점검한다.
- Do-not-show: 자동차 조사 응답유형, CI 도메인 오버레이, 실제 모집단 추정치라는 표현
- Desired length: 90~120초

## 기존 영상에서 고칠 점

- 추상 설명 장면을 줄이고 10초 안에 실제 제품 결과를 보여준다.
- 작은 전체 화면 대신 핵심 결과가 읽히는 큰 화면과 짧은 자막을 사용한다.
- 설문 복원 영상을 별도 이야기로 두지 않고 품질검토·합성 파일럿의 입력 단계로 연결한다.
- Persona Pilot의 현재 범위를 성별·연령대·지역 등 인구학적 속성으로 한정한다.
- 결정적 오류와 연구자 검토 후보를 같은 '오류'로 표현하지 않는다.
- 운영 검증 수치와 SHA는 렌더 시점 캡처 보고서에 남긴다.

## 검증 경계

- 설문 복원기는 원본에 없는 내용을 만들어 내지 않는다.
- Survey Quality Review의 `REVIEW_REQUIRED`는 결정적 오류와 다르다.
- Persona Pilot은 실제 사람의 응답이나 모집단 추정치를 대체하지 않는다.
- 운영 캡처에는 비밀키, 세션 토큰, 개인 응답자료를 포함하지 않는다.
