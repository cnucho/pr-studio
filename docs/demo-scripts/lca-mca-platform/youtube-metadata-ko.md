# YouTube 게시 정보

채널: MethodIQ

## 소개 영상

제목: `연구문제에서 보고서까지 | LCA·MCA 분석 앱 소개`

설명:

```text
LCA·MCA 분석 앱은 연구문제와 설문 자료로 잠재유형 또는 범주 관계를 탐색하고, 연구자의 검토·승인을 거쳐 DOCX 보고서를 만듭니다. 두 방법은 동등한 별도 경로입니다.

영상은 완전 합성 1,800명·21변수 예제를 실제 앱에 불러와 촬영했습니다. 미리 계산한 분석 결과를 재생하지 않습니다.

예제 자료와 매뉴얼: https://github.com/cnucho/research-app-examples/releases/tag/lca-mca-tutorial-v1
앱 코드: https://github.com/cnucho/lca-mca-platform

이 예제는 교육용이며 실제 모집단 추정, 인과효과, 예측의 근거가 아닙니다.
```

## 따라하기 영상

제목: `가상자료로 직접 실행하는 LCA·MCA | 자료 불러오기부터 DOCX 보고서까지`

설명:

```text
같은 가상 설문 파일을 내려받아 LCA와 MCA를 각각 실행하고, 결과 검토·승인을 거쳐 최종 DOCX를 받는 과정을 따라합니다.

예제 자료와 매뉴얼: https://github.com/cnucho/research-app-examples/releases/tag/lca-mca-tutorial-v1
문항·시나리오: https://github.com/cnucho/research-app-examples/blob/main/lca-mca-platform/tutorial-v1/questionnaire-ko.md
앱 코드: https://github.com/cnucho/lca-mca-platform

완전 합성 자료 1,800명·21변수입니다. 실제 연구 결과가 아닙니다. 영상에서 K=3이 수렴하지 않으면 선택하지 않고, 수렴한 실행의 QC와 제한을 확인합니다. MCA 범주 지도의 근접성은 인과관계가 아닙니다.
```

자막 파일: `intro/lca-mca-intro-ko.srt`, `tutorial/lca-mca-tutorial-ko.srt`.
게시 URL: 업로드 후 기입.
