# YouTube Release Package — English Survey Platform Videos

## Video 1 — Product Overview

### Title

**A Practical Survey Production Workspace for National Statistical Offices**

### Alternative Titles

- **From Survey Template to Tested Response Screen**
- **A Connected Survey Production Workflow for Statistical Offices**
- **Survey Production in One Guided Workspace**

### Description

This product overview presents a survey-production workspace designed for institutional use. Using a running application and synthetic data, it shows how a user can:

- start a survey project from a reusable template;
- follow a visible project workflow;
- record and resolve questionnaire review findings;
- approve a reviewed questionnaire;
- run pre-collection technical checks;
- inspect the generated response preview.

The current product is a survey-production core. A complete national implementation may also connect sample and case management, interviewer assignments, visit tracking, fieldwork monitoring, enterprise identity, full validation-rule governance, disaster recovery, statistical processing, and official-output systems.

This public demonstration intentionally excludes proprietary implementation details, source code, credentials, and real statistical data.

## Video 2 — Guided Tutorial

### Title

**Survey Workflow Tutorial: From Template to Tested Response Screen**

### Alternative Titles

- **Survey Project Tutorial — Template, Review, Test, and Preview**
- **How to Prepare and Test a Survey Before Collection**
- **Step-by-Step Survey Workflow for Institutional Teams**

### Description

This guided tutorial uses a running survey application and synthetic data. It demonstrates how a user:

1. opens the survey-template catalog;
2. creates a household survey project;
3. reads the project status and next action;
4. opens an internal review;
5. records a blocking comment;
6. resolves the finding and approves the review;
7. runs the technical test;
8. reads the visible test results;
9. opens the tested response preview;
10. enters synthetic answers without creating a production submission.

The interface shown in this recording uses one of the application’s currently supported languages. English narration and subtitles explain each step.

This tutorial does not disclose source code, private validation logic, hidden prompts, signing internals, or reusable cross-country platform-factory methods. No real respondent or official statistical-office data is used.
