## Public Disclosure Rule

Show the actual product workflow, visible capability, present scope, and complementary systems. Do not disclose source code, private validation methods, hidden prompts or orchestration, scoring or thresholds, signing internals, acceptance harnesses, corruption fixtures, credentials, real statistical data, or the reusable cross-country platform factory.

## Recording Rule

The final product overview and tutorial must show a running application with real user-visible interactions. Static slides may be used only for opening, closing, and concise scope summaries.
