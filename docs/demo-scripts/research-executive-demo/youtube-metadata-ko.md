# YouTube 게시 메타데이터 초안

## 제목

조사 결과에서 PPT 보고서까지 | MethodIQ 통합 시각화·문서 검토 데모

## 설명

조사·연구회사의 경영진과 연구책임자를 위한 MethodIQ 통합 소개 영상입니다.

Chart Studio, Diagram Studio, Survey Visualization, PowerPoint 편집기와 gWriter가 조사 결과의 설명, 발표자료 제작, 보고 문안 검토를 어떻게 연결하는지 보여 줍니다.

이 영상의 화면은 제품 기능을 설명하기 위한 편집형 재구성 장면입니다. 실제 고객 원자료나 검증되지 않은 성과 수치는 사용하지 않았습니다. 자동 생성 결과는 값·단위·분모·출처·해석 범위를 사람이 검토해야 합니다.
