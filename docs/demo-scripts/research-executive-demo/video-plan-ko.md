# MethodIQ 통합 시연 영상계획서

## 제작 개요

- 형식: 경영진용 제품 소개 영상
- 목표 길이: 2분 10초~2분 50초
- 해상도: 1920×1080
- 프레임률: 30fps
- 음성: Google Cloud TTS Chirp 3 HD 우선, OpenAI TTS 폴백
- 자막: 의미 요약형 SRT 별도 제공
- 톤: 차분하고 사실 중심의 연구·보고 환경 설명

## 구성 원칙

- 기능 목록보다 의사결정 흐름을 먼저 제시한다.
- 한 장면에는 하나의 판단만 둔다.
- 자동 생성보다 검토 가능성과 편집 가능성을 강조한다.
- 실제 화면 녹화가 아닌 장면은 설명용 재구성 화면임을 제작 문서에 명시한다.

| 05 | 설문 응답 구조 | 분모와 문항별 응답을 함께 표시 | 12초 |
| 06 | 검증 카드 | 사실·지각·맥락 검증 | 12초 |

## 검증 계획

- PR Studio 린트와 프로덕션 빌드
- 모든 장면 프레임 생성 확인
- 음성 공급자와 음성 파일 길이 기록
- ffprobe로 코덱·해상도·길이·크기 확인
- ffmpeg 전체 디코드 검사
- 3개 표본 프레임 육안 확인
- SRT와 장면별 대본 별도 보존
