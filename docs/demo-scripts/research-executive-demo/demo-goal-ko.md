# MethodIQ 통합 시연 목표

## 1. 시연 목적

조사·연구회사의 경영진이 MethodIQ 도구를 개별 기능 모음이 아니라 조사 결과의 설명, 보고, 검토를 연결하는 제작 체계로 이해하도록 한다.

## 2. 핵심 메시지

조사 결과를 해석 가능한 시각물로 바꾸고, 발표자료와 검토 문서까지 연결하는 반복 작업을 하나의 일관된 흐름으로 운영할 수 있다.

## 3. 대상의 주요 관심사

- 연구원이 도구 사용법을 새로 익히는 데 드는 시간
- 차트와 보고서의 품질 편차
- 조사 결과의 분모·단위·출처 표시
- 편집 가능한 납품물 제공 여부
- 기존 조사·보고 프로세스와의 결합 가능성

## 4. 반드시 보여 줄 내용

- 같은 조사자료가 차트, 도식, 설문 시각화로 구분되는 기준
- 시각화가 PowerPoint 산출물로 이어지는 과정
- 보고 문안이 gWriter 검토 단계로 이어지는 과정
- 자동 생성 이후에도 사람이 수치와 해석을 검토하는 통제 지점

## 5. 제외할 내용

- 실제 고객사 또는 비공개 조사 원자료
- 검증하지 않은 시간·비용 절감률
- 완전 자동화 또는 오류 없는 분석이라는 표현
- 내부 인증정보, 세션 주소, 로컬 경로

## 6. 성공 기준

- 시청 후 30초 안에 다섯 도구의 역할 차이를 설명할 수 있다.
- 시각화에서 PPTX와 문서 검토까지 이어지는 흐름을 이해한다.
- 실제 도입 검토를 위해 필요한 자료 형식, 사용자 역할, 검수 기준에 관한 질문이 나온다.
