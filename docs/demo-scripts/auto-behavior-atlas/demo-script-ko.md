# AutoBehavior Atlas 소개 및 사용법 영상

## 제작 개요

- 대상 앱: AutoBehavior Atlas
- 대상 시청자: Consumer Insight의 자동차 기획조사를 아직 구독하지 않지만 자동차 소비자 조사에 관심을 가질 수 있는 마케팅, 상품기획, 전략, CX, 리서치 담당자
- 영상 유형: 1부 제품 소개 + 2부 실제 사용법
- 핵심 약속: 보고서에 미리 실리지 않은 실무 질문도 같은 기획조사 자료에서 근거 있는 답을 찾아 후속 질문으로 발전시킨다.
- 표현 경계: Atlas에 연결된 관측 집계만 수치로 제시한다. 개인 예측, 인과효과, 지원되지 않는 40대 여성 복합조건은 시연하지 않는다.
- 음성: Google Cloud Text-to-Speech, `ko-KR-Chirp3-HD-Kore`, 속도 0.94
- 화면 자막: 음성 전문이 아니라 각 장면의 핵심 의미만 표시

## 1부. AutoBehavior Atlas 소개

### 장면 1 — 보고서에 없던 질문

- 화면: 제목 카드와 자동차 조사 보고서의 고정 목차를 상징하는 카드
- 음성: 자동차 시장에 관심은 있지만, 정기 기획조사를 구독하지 않는 분들이 있습니다. 조사 내용이 부족해서가 아니라, 보고서의 질문과 자신의 업무 질문이 정확히 만나지 않았기 때문입니다.
- 자막: 보고서의 질문과 내 업무의 질문이 다를 때

### 장면 2 — 고정 보고서의 한계

- 화면: `SUV 구매희망자의 특성`이라는 일반 결과와 더 구체적인 실무 질문을 대비
- 음성: 보고서는 모든 고객의 질문을 미리 담을 수 없습니다. 예를 들어 SUV 구매희망자의 특성이 실려 있어도, 특정 브랜드 담당자에게는 너무 일반적일 수 있습니다.
- 자막: 보고서는 모든 고객의 질문을 미리 담을 수 없습니다

### 장면 3 — 질문을 바꾸면 가치가 달라진다

- 화면: “쏘렌토와 싼타페를 함께 고려하는 여성은 현재 어떤 브랜드를 보유하고 있으며, 한 모델만 고려하는 사람과 무엇이 다른가?”
- 음성: 하지만 쏘렌토와 싼타페를 함께 고려하는 여성은 현재 어떤 브랜드를 보유하는지, 한 모델만 고려하는 사람과 무엇이 다른지 물을 수 있다면 같은 조사자료의 가치가 달라집니다.
- 자막: 일반적인 결과를 내 업무의 질문으로

### 장면 4 — Atlas의 역할

- 화면: 질문 → 관측 근거 → 표·차트·해석 → 후속 질문
- 음성: 오토 비헤이비어 아틀라스는 보고서를 다시 보여주는 도구가 아닙니다. 사용자의 질문에서 출발해 실제 조사 집계를 찾고, 수치와 해석을 함께 보여주며, 다음 질문까지 이어가게 합니다.
- 자막: 질문에서 근거까지 이어지는 자동차 인사이트 탐색

## 2부. 실제 사용법

### 장면 5 — 질문창 열기

- 화면: 운영 중인 AutoBehavior Atlas 첫 화면
- 음성: 사용법은 간단합니다. 통계 변수나 분석 명령 대신, 평소 업무에서 사용하는 말로 질문합니다.
- 자막: 1. 평소 업무의 말로 질문합니다

### 장면 6 — 첫 질문 입력

- 화면: `2025년 구매희망 모델에서 쏘렌토와 싼타페를 비교해줘.` 입력 상태
- 음성: 먼저 이천이십오 년 구매희망 모델에서 쏘렌토와 싼타페를 비교해 달라고 입력합니다.
- 자막: 쏘렌토와 싼타페 구매희망 비교

### 장면 7 — 첫 결과 확인

- 화면: 실제 전체 적격 응답 비교 결과
- 음성: Atlas는 두 모델의 관측 비중을 같은 모집단과 같은 기준으로 비교합니다. 답변에는 결론만이 아니라 표본과 근거 범위도 함께 표시됩니다.
- 자막: 같은 모집단과 기준으로 비교

### 장면 8 — 공동고려 후속 질문

- 화면: `두 모델을 함께 고려한 사람의 비중도 보여줘.` 결과
- 음성: 결과를 본 뒤, 두 모델을 함께 고려한 여성의 비중을 이어서 묻습니다. 유효 응답에서 두 모델을 모두 고려한 비중은 일 점 사 이 퍼센트로 확인됩니다.
- 자막: 후속 질문 — 여성 공동고려 1.42%

### 장면 9 — 실무 질문으로 더 깊게

- 화면: 여성 고려집합별 현재 보유 브랜드와 취득시점 결과
- 음성: 이제 현재 보유 브랜드와 최근 취득 비중을 묻습니다. 쏘렌토만 고려한 여성은 기아 보유 비중이 사십칠 점 칠오 퍼센트, 싼타페만 고려한 여성은 현대 보유 비중이 사십팔 점 팔팔 퍼센트로 가장 높았습니다. 최근 열두 달 안에 주사용차를 취득한 비중도 함께 비교됩니다.
- 자막: 보유 브랜드와 최근 취득까지 연결

### 장면 10 — 최종 가치

- 화면: `보고서 판매 → 반복 사용되는 조사 서비스` 전환
- 음성: 이렇게 기획조사는 한 번 읽고 끝나는 보고서에서, 고객이 자신의 질문으로 계속 사용하는 조사 서비스가 됩니다. 보고서에서 가치를 찾지 못했던 사람에게도, 필요한 답을 직접 발견할 새로운 이유가 생깁니다.
- 자막: 보고서를 넘어, 계속 사용하는 조사 서비스로

## 실제 시연 질문

1. `2025년 구매희망 모델에서 쏘렌토와 싼타페를 비교해줘.`
2. `이번에는 여성만 비교해줘.`
3. `두 모델을 함께 고려한 사람의 비중도 보여줘.`
4. `쏘렌토와 싼타페를 고려하는 여성 고객은 현재 어떤 브랜드 차량을 보유하고 있으며, 현재 주사용차를 최근 12개월 내 취득한 비중은 어떻게 다른가?`

## 검증 기준

- 운영 앱 화면에서 실제 질문을 실행해 캡처할 것
- 최종 결과의 1.42%, 47.75%, 48.88%가 운영 API 결과와 일치할 것
- 음성 공급자가 Google인지 렌더 보고서에 기록할 것
- 1920×1080, H.264/AAC, 자막 포함 MP4로 만들 것
- 완성본을 실제 재생하고 음성·자막·화면의 순서를 확인할 것
