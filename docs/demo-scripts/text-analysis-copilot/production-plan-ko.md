# Text Analysis Copilot 소개 영상 제작안

## 공통 제작 기준

- 제작 도구: PR Studio 렌더 파이프라인
- 화면: Text Analysis Copilot 프로덕션의 실제 공개 화면
- 음성: Google Cloud Text-to-Speech `ko-KR-Chirp3-HD-Kore`, 속도 `0.94`
- 규격: 1920×1080, H.264/AAC, 30 fps, 한국어 SRT 별도 제공
- 핵심 원칙: AI 출력이나 공개 자료 어댑터 결과를 자동으로 타당한 연구·완전한 모집단이라고 표현하지 않는다.

## 1부 · AI 시대에도 과학적 텍스트 분석이 필요한 이유

1. AI 코딩 도구는 선택지를 넓히지만 연구의 타당성을 자동으로 보장하지 않는다.
2. 텍스트 분석은 내용분석, 주제분석, 인터뷰·FGI, 프레임, 담론, 내러티브, 정책근거 등 방법이 다양하다.
3. 연구문제, 코퍼스 경계, 표집, 분석단위, 코드북, 신뢰도, 근거와 한계를 연결해야 한다.
4. 어떤 도구를 어떤 순서로 왜 사용했는지 워크플로 기록을 남겨야 한다.
5. 앱은 연구자를 대신해 정답을 선언하지 않고, 검토할 근거와 불확실성을 보존한다.

## 2부 · 여러 분석방법과 사전 구성 워크플로 사용법

1. 준비된 코퍼스를 가져오거나 범위를 정한 공개 URL·RSS/Atom·설정된 YouTube 소스를 사용한다.
2. 연구문제, 코퍼스 경계, 분석단위와 비교 변수를 먼저 정한다.
3. 연구문제에 맞는 사전 구성 워크플로를 선택하고 프로젝트 프로토콜을 고정한다.
4. 메시지 추출과 코드북 적용 뒤 불확실 사례를 사람이 검토한다.
5. 분모, 코더 불일치, 신뢰도·타당도, 대표 근거와 한계를 확인한다.
6. 보고서와 연구 영수증을 내보내고, 필요하면 MCP에서 같은 절차를 실행한다.
