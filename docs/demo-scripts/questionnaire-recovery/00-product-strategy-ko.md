# 설문 복원 및 코드북 데모 전략

## 대상과 핵심 약속

- 대상: 설문 원본, 웹 설문, 분석 데이터가 서로 달라 AI 분석을 시작하지 못하는 조사·분석 실무자
- 문제: AI에게 일을 시키려 해도 확실한 설문지와 변수·보기·분기 정보가 없으면 AI는 추측할 수밖에 없다.
- 약속: DOCX, HWPX, question.js를 실행하지 않고 읽어 문항·보기·분기를 복원하고, 불확실한 부분은 숨기지 않고 근거와 함께 검토 대상으로 남긴다.
- 결과: 사람이 불확실한 부분만 확인한 뒤, 검색형 코드북과 메타데이터를 AI에 전달할 수 있다.

## 1편 — 설문지가 없어서 AI도 헤맨다

코믹한 상황으로 시작한다. 연구자는 “AI야, 이 조사 분석해 줘”라고 말하지만 AI는 설문지와 변수 정의를 요구한다. 폴더에는 `최종`, `최종_진짜`, `최종_진짜_v7`, `question.js`가 있고 서로 내용이 다르다. 연구자가 보이는 문항만 복사하면 보기와 분기가 빠지고, AI는 자신 있게 틀린 해석을 만든다. 설문 복원 앱은 이 혼란을 하나의 검토 가능한 설문지와 코드북으로 바꾼다.

## 2편 — 실제 사용법

1. CI Portal에서 앱을 연다.
2. DOCX·HWPX 또는 question.js를 입력한다.
3. 복원된 문항·보기·분기를 확인한다.
4. `원문 확인 필요` 표시가 있는 불확실한 부분만 검토한다.
5. 검색형 코드북에서 변수명, 라벨, 값 라벨, 응답조건을 찾는다.
6. 기본 메타 JSON 또는 MCP를 통해 AI에 정확한 설문 구조를 전달한다.

## 데모 경계

- 앱 자체가 설문 내용을 임의로 완성하지 않는다.
- `검토 필요` 건수는 실패 문항 수가 아니라 보수적으로 남긴 원문 근거 확인 항목을 포함한다.
- 결측값·측정수준·파생변수·가중치·분석표는 데이터 클리닝 이후 확정한다.
- AI 제안은 사람이 확인한 뒤에만 반영한다.
