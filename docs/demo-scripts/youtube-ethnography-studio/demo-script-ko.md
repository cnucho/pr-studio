# MethodIQ EthnoLens 소개 영상

- 대상: YouTube를 소비자·사회과학 연구자료로 활용하려는 연구자
- 핵심 문제: 검색 결과 몇 개를 보고 대화창에서 바로 해석하면 표집 근거, 반례, 누락, 사례별 균형이 사라진다.
- 핵심 해결: 연구 범위와 사례를 먼저 고정하고, 수집된 근거를 사례별 페이지로 대화창에 전달한다. AI와 연구자가 관찰·해석·반론을 차례로 논의한 뒤에만 결론을 남긴다.
- 제품 경계: 자동 보고서 생성기가 아니다. MCP가 자료와 논의 순서를 관리하고, AI 대화창이 실제 해석을 수행하며, 연구자가 결론을 승인한다.
- 실제 데모 자료: 전기차 전환 경험 연구 재분석본. 후보 119건, 포함 사례 9건, 근거 1,634건.
- 음성: Google Cloud Text-to-Speech, 남성 `ko-KR-Chirp3-HD-Kore`, 속도 `0.94`

## 장면

1. 유튜브를 많이 봤다고 연구가 되는 것은 아니다.
2. 대화창만으로는 표집 근거, 사례 균형, 반례와 누락을 관리하기 어렵다.
3. EthnoLens는 연구 범위, 포함·제외 이유, 수집 근거를 먼저 고정한다.
4. 실제 재분석 화면에서 119건→9건→1,634건의 연구 필드를 보여준다.
5. MCP가 한 사례의 근거를 작은 페이지로 대화창에 보내고, 끝까지 전달되기 전에는 사례 결론을 막는다.
6. AI의 해석과 연구자의 반론을 함께 기록한다.
7. 완료되지 않은 분석은 완료된 것처럼 보이지 않으며, 누락과 한계를 화면에 드러낸다.
8. 최종적으로 근거를 추적할 수 있는 주장, 보고서, 후속 도구용 handoff를 만든다.
9. “검색에서 결론으로 점프하지 않게 하는 연구 진행자”라는 제품 메시지로 마무리한다.
