# MCP Live Usage Demo 운영 기준

기존 소개영상과 튜토리얼은 유지한다. MCP 사용기록형 영상은 기존 영상을 대체하지 않고 별도 영상으로 추가한다. 기존 영상은 같은 목적과 형식에서 완성도가 명확히 높아질 때만 교체한다.

## 인증과 API 경계

- 사용기록형 데모의 실제 실행 주체는 ChatGPT/Codex에 연결된 MCP 도구다.
- PR Studio는 MCP 실행 이벤트를 영상으로 편집·렌더링하는 제작 도구다.
- 이 제작 흐름에는 별도의 OpenAI API 키가 필요하지 않다.
- 대상 MCP 서비스가 요구하는 로그인·권한은 해당 커넥터의 연결 정책을 따른다.

## 영상 한 쌍의 역할

| 영상 | 답하는 질문 | 구성 |
| --- | --- | --- |
| 소개·튜토리얼 | 이 도구는 무엇이며 어떤 순서로 쓰는가 | 짧은 개요, 기능 구조, 사용 순서 |
| MCP Live Usage Demo | 대화창에서 지시하면 실제로 무엇이 일어나는가 | 사용자 지시, MCP 호출, 도구 결과, AI 설명 |

## 기록 원칙

1. ChatGPT 또는 Codex 대화창에서 실제 연결된 MCP 도구를 호출한다.
2. 사용자의 지시는 한 화면에서 읽을 수 있는 길이로 작성한다.
3. MCP 도구명, 실행 대기, 반환 결과를 숨기지 않는다.
4. 도구 결과를 미리 만든 응답으로 바꾸거나 성공한 것처럼 꾸미지 않는다.
5. AI의 설명은 MCP가 실제로 반환한 결과 범위 안에서만 작성한다.
6. 설득 문구, 효율성 주장, 배경 음악, 과도한 장면 전환을 넣지 않는다.
7. 오류나 제한이 있으면 그 상태와 다음 조치도 그대로 기록한다.
8. 원본 대화 이벤트, 사용한 MCP 도구, 결과 요약, 영상 해시와 전체 디코드 결과를 보관한다.
9. 외부 편집기로 handoff되는 도구는 실제 편집기 화면을 녹화하고, 완료 후 MCP가 반환한 최종 상태와 문서 해시를 다시 확인한다.

## Chart Studio 실제 사용 기록

차트 영상은 실제 Chart Studio 편집기를 실행해 녹화한다. 가상데이터 XLSX의 `01_그룹비교`와 `03_선택흐름` 시트를 차례로 불러오고, 비교 차트·Sankey·기술적 해석·PPTX 전달을 기록한다.

```powershell
npm run record:chart-studio-office-demo
```

출력은 `out/live-usage-demos/chart-studio-office-live-usage/`에 생성된다. 영상은 무음 실제 사용기록형이며, 단계 안내 자막만 사용한다.

## 제작 흐름

1. 대상 앱에 맞는 MCP 도구와 안전한 합성·공개 자료를 선택한다.
2. `사용자 지시 → MCP 호출 → MCP 결과 → AI 요약` 이벤트를 JSONL로 보존한다.
3. PR Studio에서 대화 장면을 시간순으로 렌더링한다.
4. 실제 화면이 필요한 경우 MCP 앱의 검토 화면을 이어 붙인다.
5. FFmpeg 전체 디코드, 글자 가독성, 도구명·결과 일치 여부를 검수한다.
6. CI Portal에는 기존 소개영상과 별도 카드로 추가한다.

## 우선 적용 순서

1. gWriter/GPT Editor
2. Chart Studio
3. Diagram Studio
4. PPTX Studio
5. 설문 복원·정제·품질관리
6. Evidence Ledger·ResearchPilot·Academic Writing Workspace
7. 금융·OTT·기타 분석 앱

모든 앱은 기존 소개영상 옆에 Live Usage Demo를 별도 등록한다. 공개 범위는 기존 앱과 데이터의 접근 정책을 그대로 따른다.
