# 오피스 작업 데모 구성

## 주 영상

`Chart Studio 실제 사용 기록`을 중심으로 사용한다. 화면에서 가상데이터 XLSX를 불러오고 비교 차트와 Sankey를 실제로 만든다. 이어서 기술적 해석과 PPTX 전달 버튼까지 보여준다.

기존 `Chart Studio 사용법` 영상은 스타일 프리셋과 고급 차트 범위를 설명하는 보조 영상으로 남긴다. 기존 Sankey 장면은 단계별 이탈이 한 노드에 합쳐지고 화면이 잘렸으므로 사용하지 않는다.

## 시연 순서

| 구간 | 화면 | 설명 |
| --- | --- | --- |
| 00:00–00:15 | 가상데이터 파일과 시트 목록 | 데이터가 없는 상황에서도 즉시 시연할 수 있음을 보여준다. |
| 00:15–00:40 | `01_그룹비교` 불러오기 | Excel 시트를 선택하면 기본 비교 차트가 자동 완성된다. |
| 00:40–01:15 | `03_선택흐름` 불러오기 | `source·target·value`를 인식해 Sankey를 만든다. |
| 01:15–01:35 | Sankey 결과 확인 | 인지 후 비검토 390명, 상세 검토 후 중단 255명을 분리해 단계별 이탈을 구분한다. |
| 01:35–01:50 | 데이터 해석 | 수치 범위와 흐름만 요약하고 원인이나 통계적 유의성은 추측하지 않는다. |
| 01:50–02:05 | PPTX로 보내기 | 같은 차트를 PPTX 작업으로 넘긴다. |

## 데이터 묶음

`methodiq-chart-demo-synthetic-data.xlsx`에는 다음 시트가 들어 있다.

- `01_그룹비교`: 막대·세로막대
- `02_월별추이`: 선·콤보
- `03_선택흐름`: Sankey
- `04_중요도만족도`: Sunflower
- `05_전후변화`: Slope
- `06_히트맵`: Heatmap

모든 값은 데모용 가상데이터다. 실제 조사 결과로 소개하지 않는다.

## 현장 운영

주 영상은 끊김 위험이 없는 녹화본으로 보여준다. 영상이 끝난 뒤 같은 XLSX의 `01_그룹비교`를 한 번 직접 불러오는 짧은 실시간 시연을 붙인다. Sankey는 녹화본을 기본으로 사용하고, 네트워크와 연결 상태가 확인된 경우에만 같은 시트를 다시 불러온다.
