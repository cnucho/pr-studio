# PR Studio 2.0 단계 1 감사

- 단계: 콘텐츠 기획 계약과 제작 게이트
- 감사 기준: `docs/plans/2026-10-25-pr-studio-2.0-implementation.md`
- 대상 브랜치: `agent/pr-studio-2.0`

## 계획 감사

### 고정 목표와의 일치

단계 1은 영상 효과나 제작 도구를 늘리지 않고 콘텐츠 적절성, 음성·자막·화면의 적절성을 기획 계약에 표현하는 데 집중한다. 고정된 궁극 목표와 일치한다.

### 수용한 의견

- 콘텐츠 적절성을 하나의 boolean으로 축약하지 않고 목적, 대상, 장면 논리, 근거, 음성, 자막과 화면으로 나눠 기록한다.
- 자유 문장 수집 지시는 유지하되 실행 연결용 `capabilityId`를 함께 둔다.
- 모델 결정과 콘텐츠 준비 판정을 분리해 둘 다 통과해야 제작할 수 있게 한다.
- 영상 종류별로 사용할 수 있는 화면을 기획 입력과 매니페스트 생성 양쪽에서 제한한다.

### 보류한 의견

- DB 회차 저장과 워커 재개는 단계 2에서 구현한다.
- 실제 수집기와 3회 순환은 단계 3에서 구현한다.
- 장면 목적과 전환 이유를 매니페스트에 추가하는 작업은 단계 4에서 구현한다.
- 외부 영상 분석기 설치는 Railway와 입력 경계가 확정되는 단계 7에서 수행한다.

### 계획 감사 결론

단계 1의 범위는 궁극 목표에 직접 기여하며 다음 단계의 기반으로 적절하다. 구현 진행 가능.

## 구현 감사

### 구현 결과

- `lib/video-planning.ts`에 구조화된 브리프, 수집 지시, 콘텐츠 점검과 기획 회차 계약을 추가했다.
- 콘텐츠 점검을 목적, 대상, 장면 논리, 근거, 음성, 자막과 화면 적절성으로 분리했다.
- 모델 응답의 `collectionOrders`, `contentReview`, `decision`과 beat 초안을 계획 객체에 보존했다.
- `produce`, 전체 콘텐츠 기준 통과, 미해결 문제 없음, 유효한 모델 장면이라는 조건을 모두 만족해야 `productionReady`가 되게 했다.
- 모델 연결 또는 응답 검증 실패는 `collect` 상태의 비제작 계획으로 남긴다.
- 인라인 및 큐 API 경로에서 준비되지 않은 계획이 촬영으로 넘어가지 않게 했다.
- 기획 dossier와 매니페스트가 선택된 영상 종류 및 공통 화면만 허용하게 했다.
- 모델 JSON Schema와 같은 제한을 Zod 런타임 검증으로 다시 확인하게 했다.

### 자동 검증 증거

- `npm test`: 5개 파일, 69개 테스트 통과
- `npm run lint`: 통과
- `npm run build`: Next.js production build 통과
- 추가 회귀 테스트:
  - 모델 키가 없을 때 자동 제작하지 않음
  - 콘텐츠 기획이 준비되지 않으면 촬영 전에 중단
  - 불완전한 모델 응답을 제작 계획으로 인정하지 않음
  - 다른 영상 종류의 화면을 매니페스트에서 제외
  - 콘텐츠 점검 전체 통과와 `produce`가 함께 있어야 제작 가능
  - 구조화된 브리프 길이 제한

### 감사에서 발견하고 수용한 수정

1. 모델 strict JSON Schema만으로는 런타임 안전성이 충분하지 않다.
   - 결정: `수용`
   - 처리: 동일 제약을 Zod로 검증하고 실패 시 비제작 계획으로 전환했다.
2. `video-agent.ts`가 테스트 환경에서 경로 별칭 때문에 직접 로드되지 않았다.
   - 결정: `수정 수용`
   - 처리: 같은 디렉터리 모듈은 상대 경로로 가져오게 해 제작 게이트 자체를 회귀 테스트할 수 있게 했다.

### 남은 제한

- 현재 큐 API는 준비되지 않은 계획을 DB에 저장하지 않고 422로 반환한다. 작업을 먼저 저장하고 워커가 기획하는 구조는 단계 2에서 구현한다.
- 아직 단발 기획 호출이며 수집 보고와 3회 순환은 단계 3에서 구현한다.
- 콘텐츠 점검은 모델의 구조화된 평가와 구조 검사에 기반한다. 최종 영상 기반 검증은 단계 6에서 구현한다.

### 구현 감사 결론

단계 1의 완료 조건을 충족했다. 궁극 목표를 변경하지 않았으며 이후 DB 영속화와 기획 순환이 의존할 계약과 제작 게이트가 마련됐다. 단계 2 진입 가능.
