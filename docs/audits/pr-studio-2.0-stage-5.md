## 계획 감사

### 고정 목표와의 일치

승인된 콘텐츠 계약이 실제 영상까지 손실 없이 전달되려면 제작 스크립트가 동일한 manifest와 작업 전용 파일만 사용해야 한다. 음성 길이와 자막 안전성은 자연스러운 전달의 핵심이며, 동시 작업 파일 충돌은 다른 내용의 영상이 섞이는 중대한 오류다.

### 수용할 의견

- 캡처, 렌더, 검토 스크립트에 공통 `--manifest`, `--work-dir` 계약을 적용한다.
- 렌더 스크립트는 `--output`, 검토 스크립트는 `--video`와 `--review`를 명시적으로 받는다.
- 큐 작업은 작업 ID, inline 작업은 예측하기 어려운 실행 ID로 디렉터리를 격리한다.
- 실제 TTS 음성 길이와 매니페스트 최소 화면 시간 중 큰 값을 장면 길이로 사용한다.
- manifest에 지정된 provider와 voice를 강제하며 provider 실패를 다른 음성으로 조용히 대체하지 않는다.
- ASS 제어 문자를 안전하게 변환한다.
- 승인 manifest의 내레이션과 자막만 사용하고 제작 중 임의 대체 문장을 만들지 않는다.

### 계획 감사 결론

단계 5는 콘텐츠 계약의 무결성과 자연스러운 음성·자막 전달을 지키는 구현이다. 진행 가능.

## 구현 감사

### 구현 결과

- 캡처, 렌더, 검토 스크립트가 공통 `--manifest`와 `--work-dir`을 받는다.
- 렌더러는 `--output`, 검토기는 `--video`와 `--review`를 받는다.
- 큐 작업은 작업 UUID, inline 작업은 임의 UUID 기반 전용 디렉터리를 사용한다.
- manifest, 화면, 녹화, 음성, 카드, 클립, 자막, 초안, 최종 MP4와 검토 기록이 같은 작업 디렉터리 아래에 저장된다.
- artifact ID를 UUID 형식으로 제한해 경로 탈출과 임의 공유 경로 사용을 차단한다.
- 렌더러는 실제 생성된 WAV 길이와 `minScreenTimeMs` 중 큰 값을 장면 길이로 사용한다.
- manifest의 음성 provider, voice와 speaking rate를 TTS 프로세스에 명시적으로 전달한다.
- 명시 provider가 실패하면 다른 provider나 시스템 음성으로 대체하지 않고 제작을 실패시킨다.
- ASS 자막에서 역슬래시, 중괄호와 줄바꿈을 안전하게 변환한다.
- inline 다운로드는 실행 UUID가 가리키는 작업별 최종 MP4를 읽는다.

### 감사에서 발견하고 수용한 수정

1. 큐와 inline 제작 모두 `video-assets/v2`와 `out/pr-studio-final.mp4`를 공유해 동시 작업이 서로 덮어쓸 수 있었다.
   - 결정: `수용`
   - 처리: 작업 UUID 기반 경로 생성기를 추가하고 모든 제작 명령에 같은 작업 경로를 전달했다.
2. 프리셋 provider 값은 `google-tts`였지만 음성 스크립트가 이해하는 값은 `google`이었다. 이 상태에서는 의도한 음성이 아닌 시스템 음성으로 갈 수 있었다.
   - 결정: `수용`
   - 처리: provider 식별자를 `google`로 통일하고 알 수 없는 provider는 즉시 실패시킨다.
3. ASS 자막은 중괄호만 처리해 역슬래시 기반 제어 문자열과 줄바꿈이 자막 형식을 바꿀 수 있었다.
   - 결정: `수용`
   - 처리: 역슬래시, 중괄호, 줄바꿈을 모두 ASS 안전 문자열로 변환한다.
4. 계획 당시 선택한 Google 음성의 자격 증명은 현재 검증 환경에 없지만 OpenAI 음성 자격 증명은 있었다. 고정 목표는 특정 공급자가 아니라 자연스러운 한국어 전달이다.
   - 결정: `수정 수용`
   - 처리: 명시 provider를 OpenAI `marin`으로 변경하고 한국어 제품 설명용 발화 지시를 사용한다. `auto` fallback은 사용하지 않았다.

### 자동 검증 증거

- `npm test`: 8개 파일, 80개 테스트 통과
- `npm run lint`: 통과
- `npm run build`: Next.js production build 통과
- 네 제작 관련 `.mjs` 파일에 대한 `node --check`: 통과
- 경로 격리 테스트: 서로 다른 작업 UUID의 manifest, review와 최종 MP4 경로가 겹치지 않음
- 경로 안전 테스트: `../shared`와 임의 식별자 거부
- `npm run smoke:video:production`: 실제 Chromium 캡처, OpenAI 음성 5개, 카드, ASS 자막과 MP4 합성 및 검토 통과
