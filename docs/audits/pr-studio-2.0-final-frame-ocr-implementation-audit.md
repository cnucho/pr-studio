# PR Studio 2.0 최종 프레임 OCR 구현 독립 감사

- 감사일: 2026-10-26
- 대상: `docs/plans/2026-10-26-final-frame-ocr-repair.md`의 구현
- 감사 방식: 구현 담당과 분리된 독립 코드·테스트 검토
- 최초 판정: 수정 필요
- 재감사 판정: 코드 승인

## 최초 감사 지적과 조치

### P1 — 다음 beat 누출 가능성

최초 구현은 motion 소스 종료점을 `endedAtMs + 120ms`로 잡아 다음 beat의 첫 화면이 들어오고, 렌더 패딩이 그 잘못된 프레임을 고정할 수 있었다.

조치:

- 소스 종료점을 `stableToMs`, `endedAtMs`, 다음 beat 시작 40ms 전 중 가장 이른 시점으로 제한했다.
- 100ms 이하 또는 역전된 소스 구간은 허용하지 않는다.
- motion mark가 있지만 유효한 구간을 만들 수 없으면 렌더를 즉시 실패시킨다.
- 다음 beat 경계를 넘지 않는 회귀 테스트를 추가했다.

### P1 — 프레임 추출 장애의 오분류

최초 구현은 FFmpeg 프레임 추출 실패를 건너뛰어 콘텐츠 불일치 exit 2로 끝냈다. 이 경우 동일 MP4 검토 재시도 정책이 작동하지 않았다.

조치:

- beat, sample index, 시각, 프로세스 상태, 오류를 `frameExtractionErrors`에 남긴다.
- 프레임 추출 장애를 검토 인프라 오류 exit 3으로 분류한다.
- 워커는 exit 3만 같은 MP4에 대해 검토를 한 번 재시도한다.
- 콘텐츠 불일치 exit 2는 전체 재렌더 없이 최종 실패한다.
- 실패 MP4, review, 프레임과 crop의 감사 보존 경로를 유지한다.

### P2 — 불필요한 OCR과 회귀 테스트 부족

조치:

- motion은 인접한 두 OCR 샘플이 일치하면 즉시 중단한다.
- still은 안정 샘플 한 장이 일치하면 즉시 중단한다.
- 소스 경계와 프레임 추출 오류 분류 테스트를 추가했다.

## 목표 정합성 검토

이 수리는 시각 효과를 늘리거나 외부 도구 자체를 목적으로 삼지 않는다. 계획한 핵심 콘텐츠가 실제 녹화 화면 안에 있고 최종 MP4에도 충분히 유지되는지 확인한다. 콘텐츠 적절성, 자연스러운 음성·간결한 자막, 목적에 맞는 화면이라는 고정 목표와 일치한다.

검증 문구를 축약하지 않았고, OCR 부재나 명령 실패를 통과시키지 않으며, 기술 조건과 콘텐츠 조건을 모두 만족해야 완료되는 기존 원칙을 유지했다.

## 재감사 결론

이전 P1/P2는 모두 해소됐다. 새로운 P0/P1 보안·우회·회귀와 고정 목표 충돌은 발견되지 않았다. 구현 코드를 승인한다.

초기 코드 재감사 뒤 남은 비차단 조건은 실제 `kor+eng` OCR의 반복 결정성과 최종 영상 전체 검증이었다. 아래 스테이징 운영 검증과 최종 독립 재감사에서 두 조건을 모두 해소했다.

### 불변 MP4 반복 검토

동일 해시의 다운로드 MP4와 동일 검증 계약을 사용해 현재 `review-video-v2.mjs`를 `kor+eng` Tesseract 환경에서 세 번 실행했다. 개발용 OCR 우회 옵션은 사용하지 않았다.

- 세 실행의 종료 코드는 모두 0이었다.
- 세 실행 모두 `ready`, `contentReady`, `technicalReady`가 `true`이고 `ocrMissingBeatIds`는 빈 배열이었다.
- 세 `review.json`은 바이트 단위로 동일했다.
- 동일 review SHA-256: `C1061CA61B42D1FF8C4A2BE37D52BA0A8BD7413A7ACBF6934D2BC3F7B2377F7C`
- motion 장면인 입력 화면과 생성 화면은 각각 인접한 두 OCR 샘플이 전체 관찰 문구와 일치했다.
- still 장면인 결과 화면은 안정 구간의 대상 crop에서 `YouTube 게시 패키지` 전체 문구가 일치했다.

따라서 같은 MP4의 검토 결과가 실행마다 달라졌던 기존 결함은 재현되지 않았고, 여러 프레임 중 우연히 한 장만 맞아 통과한 것도 아니다.

### 전체 타임라인과 음성·자막 검증

- 전체 영상에서 2초 간격으로 추출한 34개 시각 표본을 확인했다.
- 다섯 장면의 순서, 핵심 앱 화면, 자막 위치와 다음 beat 화면의 조기 누출이 없음을 확인했다.
- 47초 결과 장면에서 `YouTube 게시 패키지`가 완전히 보이고 자막과 겹치지 않았다.
- 오프라인 음성 전사는 기능 소개, 입력, 생성, 결과 검토, 최종 검토의 전체 발화를 장면 순서대로 포함했다.
- 음성 구간은 각 장면 시작 뒤에 시작하고 다음 장면 전에 끝났으며, 무음 경계는 장면 경계와 일치했다.
- 오디오 측정값은 integrated loudness -21.0 LUFS, LRA 5.9 LU, true peak -4.2 dBFS였고 NaN·Inf·denormal 표본은 없었다.

이 검증은 발화 내용, 타이밍, 레벨과 화면·자막 정합성을 객관적으로 확인한 것이다. 사람이 주관적으로 운율과 발음의 자연스러움을 청취했다고 주장하지 않는다. 개별 콘텐츠 게시 전 편집자 청취는 비차단 품질 확인으로 남긴다.

## 최종 독립 재감사

독립 감사자는 다음을 재검토했다.

1. 동일 MP4의 세 차례 OCR 결과와 `review.json`이 바이트 단위로 동일한가.
2. motion의 연속 두 샘플 규칙과 still의 안정 한 샘플 규칙이 실제 `kor+eng` OCR에서 지켜졌는가.
3. 전체 디코드, 34개 시각 표본, 장면 경계, 전사, 무음 경계, 자막 의미와 오디오 레벨이 서로 일치하는가.
4. 다음 beat 누출 또는 음성·화면·자막 동기 오류의 증거가 있는가.

최종 판정은 **운영 승인 가능**이다. 이전 보류 조건은 모두 해소됐으며 잔여 P0/P1 차단 위험은 없다. 이 수리는 화려함을 추가하거나 품질 게이트를 낮추지 않고, 계획한 핵심 콘텐츠가 실제 최종 영상에서 지속적으로 보이는지를 더 정확하고 감사 가능하게 확인하므로 PR Studio 2.0의 고정 목표와 일치한다.
